FCEUX ↔ Web 存档转换

FCEUX / nes.emu 的即时存档（.fc0~.fc9、.fc2，同格式）与本站 web 模拟器的即时存档（saveState）双向转换。 转换原理与字段映射见同目录 fc0conv.js 头部注释。FCEUX 存档不含游戏名，跨模拟器使用前请确认是同一 ROM。
注意：直接「写入本地槽位 / 从本地槽位导出」操作的是本浏览器 IndexedDB（NesSaveDB），操作前请先关闭正在运行的模拟器页面。
